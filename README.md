# Minecraft VR Horror – Mini Project

A Minecraft-inspired virtual reality horror survival game developed in Unity and C# as an academic mini-project at Aalborg University.

The player must survive the night by maintaining four gradually extinguishing torches using an interactive flint and steel. The experience combines immersive VR interactions, environmental feedback and spatial audio to create tension and encourage active engagement with the virtual environment.

# Technologies

- Programming Language: C#
- Game Engine: Unity 6
- VR Development: XR Interaction Toolkit
- Physics: Rigidbodies, colliders, triggers and hinge joints
- Visual Effects: Particle systems and dynamic lighting
- Version Control: Git and GitHub

  ## Applied VR Theory

| Concept | Implementation |
| --- | --- |
| **Presence and Place Illusion** | Immersive environment supported by natural head and controller tracking. |
| **Plausibility Illusion** | Responsive environmental events and progressive horror elements. |
| **Interaction Metaphors** | Natural grasping, object manipulation and tool-based interactions. |
| **Six Degrees of Freedom (6DoF)** | Positional and rotational tracking of the headset and controllers. |
| **Diegetic Feedback** | In-world clock, diminishing flames and environmental audio communicate game states. |
| **Multimodal Feedback** | Visual and auditory cues reinforce player actions and environmental changes. |
| **Spatial Audio** | Positional sound sources support spatial awareness, immersion and suspense. |
| **Physics-Based Interaction** | Rigidbodies, colliders and hinge joints enable physically responsive object manipulation. |
| **Search and Exploration** | Players actively explore their surroundings to locate and interact with objects. |
